Unit 8

Python data structures:

To effectively organise the functional and non-functional requirements defined in Task 1, two suitable data structures are dictionaries and lists. A dictionary is ideal for storing these requirements because it allows data to be stored in key-value pairs, making it easy to categorise and access specific requirements quickly. For instance, functional and non-functional requirements can each be assigned as keys, with their corresponding lists of descriptions as values. This approach provides clarity and structure, especially when working with a large or diverse set of requirements. Meanwhile, lists are useful for maintaining the order of individual requirements under each category, supporting tasks such as iteration, searching, or appending new items. The combination of dictionaries and lists ensures that the data is both organised logically and remains flexible for future expansion or modifications. (Python, 2025)
