Unit 9

Improving Code Quality.(Anaya, 2021)


Below is an image of my code before adding improvements.

Below is an image showing my change in naming strategy.

As per Mariano Anaya (2021) recommendation I went through the code and made sure that there was a consistent naming strategy. This is something that had not been done when I first wrote the code. So, I changed each class to follow the naming structure shown above.
Secondly, I went through the code and removed unnecessary comments from lines of code there is not image of this as the comments were removed. This made the code easier to read and understand as stated in Anaya (2021).
Finally based on the book of conventions from Anaya (2021) I removed magic constants and defined them all at the top of the file. This assisted with its readability and will make the code easier to maintain.

An image showing how magic consonants were removed.

References:

  • Anaya, M. (2021) Clean Code in Python. 2nd edn. Birmingham: Packt Publishing. Available at: https://learning.oreilly.com/library/view/clean-code-in/9781800560215/ (Accessed: 28/3/2025)
